# Changelog

All notable changes to GST Pro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-08-07

### Added
- **Desktop Application**: Complete offline Electron-based desktop app
- **Expense Tracking**: Add, categorize, and manage business expenses
- **GST Calculations**: Automatic GST calculations with state-wise rates
- **Income Management**: Track and manage business income streams
- **Tax Advice**: AI-powered tax consultation and guidance
- **Dashboard**: Comprehensive overview of financial data
- **Reports**: Detailed expense reports and GST summaries
- **Cross-Platform**: Support for Windows, macOS, and Linux
- **Offline Operation**: Complete functionality without internet connection
- **Local Database**: SQLite database for secure local storage
- **Modern UI**: Clean, intuitive interface using Shadcn/ui components

### Features
- **Multi-State GST Support**: Handles GST calculations for all Indian states
- **Category Management**: Pre-defined expense categories with appropriate GST rates
- **Vendor Management**: Track vendor information and state-wise transactions
- **Data Export**: Export data for accounting and compliance purposes
- **Responsive Design**: Works on all screen sizes
- **Dark/Light Theme**: User preference-based theming
- **Real-time Calculations**: Instant GST and tax calculations

### Technical
- **Frontend**: React 18 with TypeScript
- **Backend**: Python FastAPI with SQLite
- **Desktop**: Electron framework
- **UI Framework**: Tailwind CSS with Shadcn/ui
- **Build System**: Automated build process with installer generation
- **Security**: Local-only data storage with no external dependencies

### Privacy & Security
- **100% Local**: All data remains on user's computer
- **No Telemetry**: No data collection or tracking
- **Secure Storage**: Encrypted local database
- **Offline First**: Full functionality without internet connection
